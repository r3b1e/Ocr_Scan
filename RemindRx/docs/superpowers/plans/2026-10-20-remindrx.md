# RemindRx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A backend-free medication reminder app (Android-first RN) and an installable website, both storing everything locally.

**Architecture:** `shared/` holds pure TS domain logic (lifted from HealthApp `src/features/medication`) plus dose-log/adherence/backup. `mobile/` (RN 0.84 + notifee + AsyncStorage) and `web/` (Vite + React + Tailwind PWA + localStorage) each own a storage adapter, a reminder engine and UI. Both apps import `shared/` via Metro watchFolders and a Vite alias.

**Tech Stack:** TypeScript, Jest (shared), React Native 0.84.1, @notifee/react-native 9, AsyncStorage 2, lucide-react-native, Vite 6, React 19, Tailwind 3, lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-20-remindrx-design.md`

## Global Constraints
- Zero network calls. No Auth0, Firebase, analytics or API client in either app.
- Do not modify `Vivotal.HealthApp` or `Vivotal.NativeFrontend`. Copy from them instead.
- Theme tokens: primary `#0EA5E9`, primary-dark `#0284C7`, primary-tint `#E0F2FE`, accent coral `#FB7185`, accent orange `#F97316`, bg `#F8FAFC`, card `#FFFFFF`, text `#0F172A`, muted `#64748B`.
- Storage keys: `rx.meds.v1`, `rx.doses.v1`, `rx.settings.v1`. Backup `{version:1, exportedAt, meds, doses, settings}`.
- Android package `com.periscope.remindrx`, display name `RemindRx`.
- Snooze 10 min. Missed = past scheduled time + 60 min with no log entry. Rolling alarm window 14 days.
- Notification ids: `med:{id}:{YYYYMMDD}:{slot}`, plus the suffixes `:early` and `:snooze`.

## Review Focus
1. Two medicines at the same minute → two distinct reminders, no id collision (id includes medId).
2. Course end date in the past or a paused medicine → no reminders armed, and Today doesn't show it.
3. A dose whose time was moved after it was logged → the past log entry is kept, and adherence doesn't double count (log keyed by date+slot; the history view uses the log's own `scheduledAt`).
4. A corrupt or foreign JSON file is imported → rejected with a message, and existing data is untouched.
5. localStorage unavailable (private mode) → the web app still runs in memory and warns.
